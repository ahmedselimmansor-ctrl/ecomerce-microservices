# ADR 0004 — بوابة BFF بدل النداء المباشر

**الحالة:** مقبول · **التاريخ:** 2026-08-14

## السياق

صفحة المنتج تحتاج بيانات من أربع خدمات: الكتالوج، المخزون، المنتجات المشابهة، والتوصيات. ثلاثة خيارات لتجميعها.

## القرار

**BFF (Backend for Frontend)** كطبقة رقيقة تجمّع وتوجّه.

```typescript
// نداء واحد من المتصفح
GET /api/v1/bff/pdp/apple-iphone-15-128gb-black

// أربعة نداءات متوازية داخل الـ VPC
const [product, stock, similar] = await Promise.all([...]);
const recommended = await optional(recommendationCall, []);   // اختياري
```

## الأرقام التي دفعت القرار

| النهج | رحلات المتصفح | زمن تقديري (4G, RTT≈80ms) |
|---|---|---|
| نداء مباشر لكل خدمة | 4 متسلسلة | ~600 ms |
| نداء مباشر متوازٍ | 4 متوازية | ~180 ms + 4× تكلفة TLS |
| **BFF** | 1 | **~120 ms** (40ms داخل الـ VPC + رحلة واحدة) |

## البدائل المرفوضة

| البديل | سبب الرفض |
|---|---|
| المتصفح ينادي كل خدمة | يكشف الطوبولوجيا الداخلية · CORS لكل خدمة · مصادقة مكرّرة · بطيء على الشبكات الضعيفة |
| GraphQL Gateway | قوي للعملاء المتنوعين، لكنه يضيف طبقة تعقيد (N+1، تعقيد الاستعلام، تخزين مؤقت أصعب) لا يبررها عميل واحد |
| تجميع داخل خدمة موجودة | يخلط مسؤوليات العرض بمنطق المجال — الكتالوج لا يجب أن يعرف شكل صفحة المنتج |

## ما يفعله الـ BFF (وما لا يفعله)

**يفعل:** التوجيه · التحقق من JWT مرة واحدة · تحديد المعدّل الموزّع · تجميع الاستجابات · كاش Redis · حظر المسارات الداخلية · ضغط · ربط `x-request-id`.

**لا يفعل:** أي منطق أعمال · أي وصول مباشر لقاعدة بيانات · أي قرار تسعير أو صلاحية.

> **الخط الفاصل:** لو احتاج الـ BFF معرفة قاعدة عمل، فهي في المكان الخطأ.

## التدهور المتدرّج

المهم في التجميع هو تصنيف التبعيات:

```typescript
const [product, stock, similar] = await Promise.all([
  callUpstream(catalog, `/products/${sku}`),               // إلزامي — فشله = 404
  optional(inventoryCall, { inStock: true }),              // اختياري — نفترض التوفر
  optional(similarCall, []),                               // اختياري — قسم فارغ
]);
```

سقوط خدمة التوصيات يخفي قسمًا من الصفحة. سقوط الكتالوج يعني لا صفحة أصلًا — وهذا صحيح.

## العواقب

**إيجابًا:** رحلة واحدة · الطوبولوجيا الداخلية مخفية · نقطة واحدة للمصادقة والحدود والكاش · تدهور متدرّج مركزي.

**سلبًا:** نقطة فشل مركزية (يعالجها التوسّع الأفقي و PDB) · قد تصبح "monolith موزّع" إن تسرّب إليها منطق العمل — خطر حقيقي يحتاج انضباطًا في المراجعة · طبقة إضافية تحتاج نشرًا ومراقبة.
